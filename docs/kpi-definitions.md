# KPI定義

各指標の **計算式・分母・データ元** を定義します。画面・SQL・Python はすべてこの定義に従います。計算式の正式な定義は `shared/kpi-catalog.json` にあり、この文書と一致させています。

> **実装状況**: 集客ファネル（問い合わせ〜入会・CPA・CAC）を SQL 関数 `marketing_funnel()` で実装済みです。**実際の事業データではまだ検証していません**。

## 共通ルール

1. **比率の分母が0なら「計算不能」** とし、0%と表示しない。
2. **費用が未記録・権限なしなら CPA・CAC は計算不能**。0円とみなさない。
3. **期間は日本時間（Asia/Tokyo）で区切る**。
4. 件数が少ないときは結論を出さない。件数に応じて「事例レベル（n<10）」「記述統計レベル（n<30）」などを表示する。グループ比較では最も件数の少ないグループで判定する。

## 集客ファネル

件数は `marketing_funnel(org, from, to, group)` が数え、率・単価は画面（`src/lib/marketing.ts` の `funnelRates`）が件数どうしを割ります。

| 指標 | 計算式 | 分母・単位 | 注意 |
|---|---|---|---|
| 問い合わせ数 | 期間内の `inquiries` 件数 | 件 | `inquired_at` 基準 |
| 体験申込率 | 体験申込があった問い合わせ数 ÷ 問い合わせ数 | 問い合わせ数 | 体験は振替で複数行ありうるため、問い合わせごとに0/1で数える |
| 体験参加率 | 体験に参加した問い合わせ数 ÷ 体験申込があった問い合わせ数 | 体験申込数 | キャンセル・欠席は参加に含めない |
| 入会転換率（体験→入会） | 入会した問い合わせ数 ÷ 体験に参加した問い合わせ数 | 体験参加数 | 体験に参加せず入会した人も分子に入るため、100%を超えることがある |
| 入会転換率（問い合わせ→入会） | 入会した問い合わせ数 ÷ 問い合わせ数 | 問い合わせ数 | |
| 問い合わせ獲得単価（CPA） | マーケティング費用 ÷ 問い合わせ数 | 問い合わせ数 | 期間・チャネルを揃える。費用が未記録・権限なしなら計算不能（0円とみなさない） |
| 顧客獲得単価（CAC） | マーケティング費用 ÷ 新規入会数 | 入会数 | 人件費は含めない（`marketing_costs` のみ） |
| 問い合わせ→入会日数 | 入会日 − 問い合わせ日 | 日 | 中央値で表示。入会していない問い合わせは除外 |

**コホートの考え方**: 率を計算するときは「同じ期間に問い合わせた人のうち、その後入会した人」で数えます（問い合わせ月コホート）。「今月の入会数 ÷ 今月の問い合わせ数」は、別の人を割っているため使いません。直近の問い合わせはまだ入会判断前なので、成熟していない期間であることを表示します。

**費用の期間**: 費用は `occurred_on` が期間内のものを合計します（問い合わせ日と同じ期間）。広告を出した月と問い合わせが来た月がずれる場合があるため、短い期間のCPA・CACは振れやすくなります。チャネル別の費用は、費用にチャネルを付けた分だけが入ります。

**きっかけの確度**: 問い合わせのきっかけは `attribution` で確度を区別します。`tracked_link`（UTM付きリンク）以外は「参考値」と表示します。チャネル間の差は相関であり、チャネルそのものの効果とは断定しません。
